# Lab 3: Sensors and Time Reporting
## Submitted by Martin Lopez

This is the second lab using the ESP32 Feather V2 board.

This lab is focused on using external sensors to measure conditions in the environment and derive data from it. The first part of the lab uses a potentiometer, while the second part uses a touch sensor

For this lab, I will be using the PlatformIO commandline tools and a text editor (Neovim) in Linux to manage my project. The files "potentiometer.cpp" and "voltage.cpp" read from the potentiometer and print its values in different ways.

If you run either file's code, make sure any other files are commented out. PlatformIO can only have one setup and one loop function.
